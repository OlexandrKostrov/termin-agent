# termin-agent

A German-speaking AI voice agent that phones a medical practice (_Arztpraxis_) on your behalf and books an appointment (_Termin_).

You write the request in English:

> Book me a GP appointment next week, after 15:00, not Wednesday.

The agent calls the practice and negotiates in German. It returns a structured result (booked slot / no slot / call back later / voicemail / refused / dropped) and the transcript.

> **Status:** early development. M0 (scaffold) and M1 (domain, German time utilities, policy guards) are done; there is no LLM or telephony yet. See [Roadmap](#roadmap).
> The MVP never calls third parties. It calls only a simulated practice and allow-listed numbers that belong to the author.

## Why this is interesting

- **Hard rules live in code, not in prompts.** The LLM proposes typed actions. A deterministic policy guard decides whether a slot can be accepted and whether a personal-data field can be spoken. The agent cannot accept a slot outside your constraints and cannot invent personal data, even if the model misbehaves.
- **Explicit state machines.** One machine covers the request lifecycle and another covers the call. Every branch ends in a typed result.
- **German, properly.** Spoken dates and times, parsing of colloquial times ("Viertel vor vier", "halb drei"), DIN 5009 spelling, public holidays per Bundesland, all in Europe/Berlin time.
- **Compliance by construction.** The first sentence is a fixed AI disclosure naming the person the agent calls for (EU AI Act Art. 50). It is never generated by the model.
- **Measured.** A reproducible scenario-based eval suite against a simulated practice, with hard release gates: 0 constraint violations, 0 invented data, 100 % disclosure-first.

```

  domain/    zod schemas, request + call state machines, typed errors
```

## Getting started

Requirements: Node 22, pnpm 10 (`corepack enable`).

```bash
pnpm install
pnpm check        # format, lint, typecheck, test
pnpm test:coverage
```

## What M1 guarantees (and how it is tested)

| Guarantee                                            | Test                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| A slot is accepted iff it satisfies every constraint | fast-check vs. an independent `Intl`-based oracle, random offsets + DST |
| Personal data is never invented                      | property: every released value appears verbatim in the user's input     |
| Disclosure is first and exact                        | unit tests on the fixed template and transcript check                   |
| Only allow-listed numbers are dialled                | property: `ok` iff the number is on the list; exact E.164 only          |
| State machines match their spec                      | every (from, to) pair vs. an independent table; reachability; walks     |
| German times round-trip                              | property: `parseGermanTime(speakTime(h, m))` recovers `h:m`             |
